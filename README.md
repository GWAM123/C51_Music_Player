# C51_Music_Player
1. Hardware Connections:
    - Buzzer (Beep): P2.5
    - Key 1: P3.1
    - Key 2: P3.0
    - Key 3: P3.2
    - Key 4: P3.3

2. The musical notes are referenced from C4 (262 Hz).

3. The note sequences for the songs are implemented in Song.cpp.

4. The function of each key is as follows:
    - Key 1: Song of the Irish Whistle
    - Key 2: Always With Me
    - Key 3: If I Can Stop One Heart from Breaking  
    - Key 4: Pause playback
